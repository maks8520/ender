# Цель проекта
Создать кастомный сенсорный UI для Ender 3 V3 KE на базе Linux (Creality OS).
Экран физически развернут горизонтально (Landscape).
Главная цель: интеграция USB-камеры, минимализм в стиле Bambu Lab, стабильность.

# Технические ограничения
- ОС: Creality OS (Linux-based, ARM).
- Разрешение экрана: 480x320 (в ландшафтной ориентации).
- Фреймворк UI: LVGL (Light and Versatile Graphics Library).
- Бэкенд: Взаимодействие только через WebSocket API Moonraker (порт 7125).
- Ресурсы: Процессор слабый, избегать сложной прозрачности (opacity), тяжелых анимаций и частых перерисовок всего экрана. Использовать частичное обновление (invalidation).

# Требуемый функционал (MVP)
1. Главный экран: 
   - Слева: Видеопоток с локальной камеры (http://localhost:8080/?action=stream от Crowsnest).
   - Центр: Крупный прогресс-бар, время до конца, текущая температура сопла/стола.
   - Справа: Большие кнопки "Старт", "Пауза", "Стоп".
2. Обработка ошибок: Если Moonraker присылает ошибку, показывать понятное сообщение на русском языке и кнопку "Перезагрузить Klipper".
3. Скрипты установки: Должен быть создан `install.sh` (разворачивает всё, настраивает автозапуск) и `rollback.sh` (удаляет кастом и возвращает стандартный сервис).
