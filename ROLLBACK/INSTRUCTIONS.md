# Инструкция по полному откату на заводскую прошивку

## Шаг 1: Скачивание прошивки
Официальная прошивка для Ender 3 V3 KE доступна на сайте Creality:
https://www.creality.com/pages/download-ender-3-v3-ke

Или прямая ссылка (актуально на октябрь 2026):
https://file2-cdn.creality.com/file/fd5ef4b38a5ac1e0cf2aec6847137f77/Ender-3_V3_KE_F005_ota_img_V1.1.0.17.img

## Шаг 2: Подготовка флешки
1. Отформатируйте USB-флешку в FAT32.
2. Скопируйте скачанный файл прошивки в корень флешки.
3. Убедитесь, что файл называется точно так, как требует Creality (обычно `Ender3V3KE_vX.X.X.bin`).

## Шаг 3: Принудительная прошивка
1. Выключите принтер.
2. Вставьте флешку в USB-порт.
3. Зажмите кнопку на экране (или следуйте инструкции из официальной документации Creality для принудительной прошивки).
4. Включите принтер, удерживая кнопку.
5. Дождитесь завершения прошивки (экран мигнет, принтер перезагрузится).

## Альтернативный откат (через скрипт rollback.sh)
Если кастомный UI не загружается, но система работает:
1. Подключитесь по SSH: `ssh root@<IP-принтера>` (пароль: Creality2023)
2. Выполните: `sh /usr/data/custom_ui/rollback.sh`
3. Принтер перезагрузится с заводским интерфейсом.
